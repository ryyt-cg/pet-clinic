## Goal
The goal of this project is to create a pet clinic API was written in Spring using different languages and frameworks. The API should have the following endpoints:

- GET /owners
- GET /owners/{id}
- POST /owners
- PUT /owners/{id}
- DELETE /owners/{id}
- GET /pets
- GET /pets/{id}
- POST /pets
- PUT /pets/{id}
