# Pet Clinic Web Application
This is a simple web application for managing pet clinics. It allows users to add, view, and manage pets and their owners.

## Features
- Light/dark mode
- Responsive design
- Accessible UI
- Built-in Sidebar component
- Global search command
- Multiple pages for different functionalities
- Custom components for enhanced user experience

## Tech Stack
- **UI:** [MUI](https://mui.com) (MUI)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Routing:** [TanStack Router](https://tanstack.com/router/latest)
- **Type Checking:** [TypeScript](https://www.typescriptlang.org/)
- **Linting/Formatting:** [Eslint](https://eslint.org/)
    & [Prettier](https://prettier.io/)
