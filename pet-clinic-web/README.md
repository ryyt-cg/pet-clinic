# Pet Clinic Web Application
Pet Clinic Web Application built with Vite, React, TypeScript, Tailwind CSS, Shadcn/UI, TanStack Router, and TanStack Query.
It allows users to view and manage pet owners and their pets.

## Technologies Used
- Vite
- React
- TypeScript
- Tailwind CSS
- Shadcn/UI
- TanStack Router
- TanStack Query
